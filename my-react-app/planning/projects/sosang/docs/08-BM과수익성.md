# BM과 수익성

> 이 문서는 `model/` 의 데이터에서 자동으로 만들어집니다. 직접 고치지 말고 `model/` 을 고친 뒤 `npm run plan:build` 를 실행하세요.

이 문서의 숫자는 **예측이 아니라 가정이 맞을 때의 계산**입니다. 가격은 근거 없는 시안이고(D-05), 매출총이익률과 고객 획득 비용은 아직 정할 수 없습니다.

## 입력값

| 항목 | 값 | 출처 | 메모 |
| --- | --- | --- | --- |
| 월 이용료 시안(사장님 플랜) | 19,000원 | 노션 기준 | E-04. 근거 없는 시안(D-05) |
| 월 이용료 시안(단골관리 플랜) | 39,000원 | 노션 기준 | E-04. 이탈 감지는 later 기능이라 MVP 에는 없다 |
| 월 해지율 시나리오(낮음) | 5% | 노션 기준 | E-02 의 대행형 전환 기준값 |
| 월 해지율 시나리오(중간) | 10% | 검증 전 가정 | 비교용 가정 |
| 월 해지율 시나리오(높음) | 15% | 검증 전 가정 | 비교용 가정 |
| 매출총이익률 | 미정 | 검증 전 가정 | AI 생성 비용과 알림 비용을 확인하기 전에는 정할 수 없다 |
| 고객 1곳을 얻는 비용 | 미정 | 검증 전 가정 | T-03 랜딩 결과와 T-05 경로 비용을 본 뒤 정한다 |

## 민감도: 해지율에 따라 달라지는 매출

| 월 해지율 | 평균 이용 기간 | 이용자 1곳당 누적 매출(월 19,000원) |
| --- | --- | --- |
| 5% | 20.0개월 | 380,000원 |
| 10% | 10.0개월 | 190,000원 |
| 15% | 6.7개월 | 126,667원 |

- 누적 매출 = 월 이용료 × (1 ÷ 월 해지율). 매출총이익률을 곱하기 전의 값이라, 고객 획득 비용의 상한으로 쓰려면 이익률을 확정해야 합니다.
- 해지율이 5%인지 15%인지에 따라 같은 가격에서 이용자 1곳의 누적 매출이 3.0배 차이 납니다. 가격보다 **실행이 이어지는가(K-02, K-03)**가 사업성을 더 크게 좌우합니다.

## 가격 시안(노션 기획안, 확정 아님)

| 플랜 | 가격 | 포함 내용 |
| --- | --- | --- |
| 무료 | 0원 | 월 4회 발행, SNS 1채널 |
| 사장님 | 월 19,000원 | 무제한 발행, 3채널 연동, 홍보물 생성 |
| 단골관리 | 월 39,000원 | 이탈 감지, 자동 쿠폰, 매출 진단 리포트 |

이 시안은 MVP 범위(D-03)와 맞지 않는 기능(연동, 홍보물, 이탈 감지)을 포함합니다. MVP 가격 구성은 T-02, T-03 결과를 본 뒤 다시 짭니다.
