# 요구사항 명세서

> 이 문서는 `model/` 의 데이터에서 자동으로 만들어집니다. 직접 고치지 말고 `model/` 을 고친 뒤 `npm run plan:build` 를 실행하세요.

## R-01 사장님은 상호·대표 메뉴·특징 한 줄만 입력해 가게 등록을 끝낼 수 있다.

- **우선순위**: 반드시
- **다루는 문제**: P-01, P-03
- **구현 기능**: F-01 가게 등록(MVP)
- **지표**: K-01
- **인수 기준**
  - 필수 입력은 상호, 대표 메뉴(2~3개), 특징 한 줄로 한정한다
  - 등록 시작부터 완료까지 3분 이내에 끝난다(노션 사용 흐름 기준)
  - 필수 입력을 모두 채우지 않으면 완료할 수 없고, 빠진 항목을 표시한다

## R-02 등록한 가게 정보만으로 채널별 홍보 문구를 만들어 준다.

- **우선순위**: 반드시
- **다루는 문제**: P-01
- **구현 기능**: F-02 홍보 문구 만들기(MVP)
- **지표**: K-01
- **인수 기준**
  - 인스타그램, 카카오 채널, 스마트플레이스 중 채널을 선택하면 그 채널 형식의 문구를 1개 이상 만든다
  - 만든 문구는 사장님이 직접 수정할 수 있다
  - 등록하지 않은 가격·행사·효능 정보는 문구에 넣지 않는다
  - 문구를 만들 때 추가 입력을 요구하지 않는다

## R-03 정해진 시간에 '오늘 할 일' 한 개만 알려 준다.

- **우선순위**: 반드시
- **다루는 문제**: P-03, P-01
- **구현 기능**: F-03 오늘의 할 일 1개(MVP)
- **지표**: K-02
- **인수 기준**
  - 알림은 하루 한 번, 할 일은 한 개만 보낸다
  - 알림 시간을 사장님이 정할 수 있다
  - 각 할 일은 5분 이내에 끝나는 크기로 쪼갠다(노션 기획안 기준)

## R-04 할 일을 완료·건너뜀으로 기록하고 주간 수행률을 보여 준다.

- **우선순위**: 반드시
- **다루는 문제**: P-03
- **구현 기능**: F-05 실행 체크와 주간 수행률(MVP)
- **지표**: K-02, K-03
- **인수 기준**
  - 할 일마다 완료와 건너뜀 중 하나가 기록된다
  - 주간 수행률은 완료 수 ÷ 전달 수로 계산해 표시한다
  - 건너뛴 이유를 선택해 기록할 수 있다

## R-05 만든 문구를 채널에 올릴 수 있도록 복사하거나 공유 화면으로 넘겨 주고, 자동 동시 발행은 이후에 다룬다.

- **우선순위**: 가능하면
- **다루는 문제**: P-01
- **구현 기능**: F-04 문구 복사·공유(MVP), F-07 SNS 원클릭 동시 발행(다음)
- **지표**: K-02
- **인수 기준**
  - 문구를 한 번에 복사할 수 있다
  - 채널별로 올리는 방법을 한 화면 안에 안내한다
  - 게시했는지는 사장님이 직접 완료로 표시한다

## R-06 사장님 연령대에 따라 설명의 난이도와 글자 크기를 구분한다.

- **우선순위**: 가능하면
- **다루는 문제**: P-01
- **구현 기능**: F-01 가게 등록(MVP)
- **지표**: -
- **인수 기준**
  - 등록할 때 연령대를 선택 입력으로 받는다
  - 선택한 연령대별로 글자 크기와 설명 문장을 구분해 보여 준다

## R-07 유행 밈을 쉬운 말로 풀어 주고, 어떤 손님층에 맞는지 함께 안내한다.

- **우선순위**: 가능하면
- **다루는 문제**: P-01
- **구현 기능**: F-06 밈 쉬운말 설명(다음)
- **지표**: -
- **인수 기준**
  - 밈마다 뜻, 주로 반응하는 연령층, 가게 문구에 쓰는 예시를 보여 준다
  - 밈을 고르면 그 표현이 들어간 문구를 만든다

## R-08 30일 이상 방문하지 않은 단골을 알려 주고 쿠폰 발송을 제안한다.

- **우선순위**: 여유가 되면
- **다루는 문제**: P-02
- **구현 기능**: F-09 단골 이탈 감지와 쿠폰(나중)
- **지표**: -
- **인수 기준**
  - 방문 기록이 30일 이상 없는 단골을 목록으로 보여 준다
  - 쿠폰 발송은 사장님이 확인한 뒤에만 나간다

## R-09 MVP 에서 수집하는 개인정보를 사장님 계정과 가게 정보로 한정하고, 항목을 목록으로 문서화한다.

- **우선순위**: 반드시
- **다루는 문제**: P-01
- **구현 기능**: F-01 가게 등록(MVP)
- **지표**: K-08
- **인수 기준**
  - 손님의 이름·전화번호·연락처는 수집하지 않는다
  - 수집 항목 목록이 문서로 남아 있다

## R-10 인쇄용 홍보물(전단, 책자)을 템플릿으로 만든다.

- **우선순위**: 여유가 되면
- **다루는 문제**: P-01
- **구현 기능**: F-08 홍보 책자·전단 생성(나중)
- **지표**: -
- **인수 기준**
  - 템플릿을 고르고 내용을 입력하면 PDF 또는 이미지로 내려받는다

## R-11 매출이 줄었을 때 단골 감소 등 원인 후보를 보여 주는 진단 리포트를 만든다.

- **우선순위**: 여유가 되면
- **다루는 문제**: P-04
- **구현 기능**: F-10 매출 진단 리포트(나중)
- **지표**: -
- **인수 기준**
  - 원인 후보를 근거 수치와 함께 최대 3개까지 보여 준다
