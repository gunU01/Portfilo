# 동네 사장님 5분 홍보 (가칭)

> 이 문서는 `model/` 의 데이터에서 자동으로 만들어집니다. 직접 고치지 말고 `model/` 을 고친 뒤 `npm run plan:build` 를 실행하세요.

요식업 사장님이 홍보를 따로 공부하지 않고도 매일 하나씩 실행하도록 돕는 서비스

- **첫 대상**: 요식업 사장님(카페·식당). 재방문 주기가 짧은 동네 가게
- **담당**: 문채원
- **시작**: 2026-10-20
- **출처**: 팀 노션 '주제 선정 과정 > 주제 찐찐최종'의 후보 주제 '소상공인(요식업) 마케팅 서포트 서비스'와 그 하위 조사 문서
- **범위**: 출시가 아니라 기획과 검증까지를 이번 프로젝트의 범위로 한다(D-07).

## 지금 어디까지 왔나

| 단계 | 상태 | 오류 | 경고 |
| --- | --- | --- | --- |
| G1 프레임: 항목 형식과 연결이 맞다 | 통과 | 0 | 0 |
| G2 근거: 출처가 있고 확인 상태가 정직하다 | 문서 통과 · 현장 확인 대기 | 0 | 0 |
| G3 해결안: 문제 → 요구사항 → 기능 → 화면이 끊김 없이 이어진다 | 통과 | 0 | 0 |
| G4 사업성: 수익 가정과 지표 목표에 기준이 있다 | 문서 통과 · 현장 확인 대기 | 0 | 0 |
| G5 검증 설계: 모든 가설에 실험과 합격선이 있다 | 문서 통과 · 현장 확인 대기 | 0 | 0 |
| G6 범위: MVP 가 한도 안이고, 하지 않는 것이 적혀 있다 | 문서 통과 · 현장 확인 대기 | 0 | 0 |

'문서 통과'는 항목 사이의 연결과 형식이 맞다는 뜻입니다. 문제가 실제로 있는지는 인터뷰와 실험 결과가 있어야 하며, 지금은 **직접 확인한 근거가 0건**입니다. 그래서 모든 문제는 '가설' 상태입니다.
