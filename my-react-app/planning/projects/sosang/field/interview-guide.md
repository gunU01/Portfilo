# 사장님 인터뷰 가이드 (T-01, T-05)

이 문서는 손으로 쓴 가이드입니다(자동 생성 문서가 아닙니다). 질문과 기록 열은 `model/hypotheses.mjs`의 가설(H-01, H-02, H-03, H-05, H-07)과 맞춰져 있고, 기록은 `npm run plan:tally`가 집계합니다.

## 1. 목적과 원칙

- 알고 싶은 것: 사장님이 **지난 한 달에 실제로 한 일**과 **하지 못한 이유**. 서비스가 마음에 드는지는 알고 싶은 것이 아닙니다.
- 지킬 것
  1. 과거 행동을 묻는다. "~하실 것 같나요?" "~필요하세요?"는 묻지 않는다. 묻는 순간 대부분 "네"라고 답한다(E-03).
  2. 서비스 소개를 먼저 하지 않는다. 화면은 맨 끝의 밈 질문(Q9) 한 번만 보여 준다.
  3. 가격을 말하지 않는다. 지불 의사는 인터뷰가 아니라 컨시어지(T-02)와 랜딩(T-03)에서 행동으로 본다.
  4. 칭찬과 긍정 반응은 근거로 세지 않는다. 구체적인 사례(언제, 무엇을, 몇 번)가 나온 것만 기록한다.
  5. 이유는 답이 나온 뒤에 분류한다. 보기를 먼저 읽어 주지 않는다.

## 2. 모집 (T-05)

경로를 2개 이상 씁니다. 경로마다 요청 수와 수락 수를 `contacts.csv`에 한 줄씩 남겨 수락률(H-07, 합격선 20%)을 잽니다.

| 경로 | 방법 | 기록할 것 |
| --- | --- | --- |
| 직접 방문 | 한가한 시간(영업 전후)에 동네 가게를 찾아가 요청 | channel: visit |
| 소개 | 가족·지인이 아는 가게를 소개받음 | channel: referral |
| 온라인 | 사장님이 모이는 커뮤니티에 요청 글(커뮤니티 규칙 확인 후) | channel: online |

- 업종은 한 가지로 몰리지 않게 섞습니다. 업종 구성 자료(E-15)는 출처 확인 전이라 참고만 하되, 한식과 커피 전문점처럼 비중이 큰 업종을 먼저 포함합니다(D-01, T-05).
- 소개로 모은 표본은 아는 사람 쪽으로 치우칩니다. 인터뷰 결과를 정리할 때 경로별 비율을 함께 적습니다(X-07).

### 요청 메시지 예시 (괄호는 직접 채움)

방문: "안녕하세요. 저는 (학교/소속) 학생이고, 동네 가게 사장님들이 가게를 알리는 방법을 조사하는 프로젝트를 하고 있습니다. 판매나 영업이 아니고, 20~30분만 지난 한 달 이야기를 들려주시면 됩니다. 사장님 시간에 맞춰 (가게 앞/전화)로 하겠습니다."

소개: "(소개해 주신 분) 통해 연락드립니다. 가게를 알리는 일을 어떻게 하시는지 듣고 싶습니다. 판매 목적이 아니고 20~30분이면 됩니다. 가게 이름은 기록에 남기지 않습니다."

온라인: "가게를 운영하시는 분께 여쭙니다. (소속) 학생으로 사장님들이 홍보에 쓰는 시간과 방법을 조사하고 있습니다. 판매 목적이 아니고, 20~30분 이야기 나누실 분은 댓글이나 쪽지 부탁드립니다."

## 4. 질문과 기록 열

| 질문 | 기록 열 | 가설 |
| --- | --- | --- |
| Q1. 어떤 가게를 얼마나 운영하셨나요? (업종, 운영 연수) | business_type, years_open | 맥락 |
| Q2. 지난 한 달 동안 가게를 알리려고 실제로 하신 일이 있나요? 무엇을, 몇 번이요? | promo_actions_last_month (숫자) | H-01 |
| Q3. 그 이상 하지 못하셨다면 가장 큰 이유가 무엇인가요? (보기를 읽어 주지 않는다) | reason_main: time(시간), judgment(무엇을 어떻게 할지 모름), cost(돈), no_need(필요 없음), other | H-01 |
| Q4. 인스타그램·카카오 채널·네이버 플레이스 같은 걸 만들어 두고 안 쓰게 된 게 있나요? 왜 멈추셨나요? | abandoned_free_channel (Y/N), abandoned_reason | H-02 |
| Q5. 지금 홍보에 쓰시는 돈이 있나요? 배달앱 광고비나 체험단도 포함해서요. 한 달에 대략 얼마인가요? | current_promo_spend_won (숫자, 모르면 비움) | 가격 맥락(E-09) |
| Q6. 최근 한 달 동안 안 오신 단골이 떠오르시나요? 어떤 분인가요? | can_name_lapsed_regular (Y/N) | H-03 |
| Q7. (Y일 때만) 그분께 무엇을 해 보셨나요? | acted_on_lapsed_regular (Y/N, Q6가 N이면 비움) | H-03 |
| Q8. 가게 일을 하시는 중에 메시지나 알림을 가장 잘 확인하시는 곳이 어디인가요? | best_notification_channel (kakao, sms, app_push, call, other 중 말한 대로) | A-03 |
| Q9. (카드 3장을 보여 준다) 이 표현이 무슨 뜻인지 아시나요? 가게 홍보에 쓰실 것 같으세요? | meme_shown (Y/N), meme_understood (Y/N), meme_would_use (Y/N) | H-05 |

- `reason_main`이 time이나 judgment이고 `promo_actions_last_month`가 0 또는 1이면 H-01에 해당합니다. 두 조건을 모두 만족해야 합니다.
- H-03은 Q6이 N이거나, Q6이 Y인데 Q7이 N인 경우에 해당합니다.
- Q9의 카드는 밈 3개와 뜻, 어울리는 손님층을 한 장씩 적은 종이(또는 화면)입니다. 밈은 사장님 연령대에 맞춰 고르고, 어떤 밈을 보여 줬는지 `notes`에 적습니다.

## 5. 하지 말아야 할 것

- 유도하는 질문: "홍보가 어렵지 않으세요?", "이런 서비스 있으면 쓰시겠어요?"
- 서비스 설명이나 가격 제시
- 사장님 이름, 가게 이름, 전화번호 기록. ID(I-01, I-02 …)만 쓴다.
- 동의 없는 녹음과 사진

## 6. 기록과 집계

1. `field/templates/`의 두 CSV를 `field/data/`로 복사한다. `field/data/`는 저장소에 올라가지 않는다(`.gitignore`).
2. 요청할 때마다 `contacts.csv`에 한 줄(`accepted`는 Y 또는 N, 응답이 없으면 N), 인터뷰가 끝나면 `interviews.csv`에 한 줄을 적는다. 인터뷰 직후에 적는다.
3. `npm run plan:tally`로 집계한다. 표본이 목표(10명)에 못 미치면 "참고만"으로 나온다.
4. 집계를 보고 근거 장부(`model/evidence.mjs`)에 `kind: 'interview'`, `n`, `date`를 달아 옮기고, 실험 T-01을 `done`으로, 가설과 문제의 상태를 바꾼다. 근거가 모자라면 `npm run plan`이 막는다.
